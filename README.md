# 📦 Track IN

**Track IN** adalah aplikasi berbasis web yang dirancang untuk membantu anak kos mengelola keuangan harian, mencatat pengeluaran bersama, melacak inventaris barang kos, serta menyimpan catatan penting secara rapi.

🚀 **Live Demo:** [Coba Aplikasi Track IN](https://bagus477.github.io/Track-In/)

---

## 🛠️ Fitur Utama
* **Dasbor**: Monitoring saldo tunai, tren pengeluaran, dan widget fleksibel.
* **Keuangan**: Pencatatan pengeluaran pribadi dan tagihan patungan.
* **Inventaris**: Pelacakan status barang bersama, pribadi, maupun hasil patungan.
* **Catatan**: Penyimpanan catatan keuangan dan pengingat penting.
